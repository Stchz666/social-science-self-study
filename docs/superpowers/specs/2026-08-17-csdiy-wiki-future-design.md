# CSDIY 辅助参考与未来 Wiki 设想

## 背景

当前学习中枢以 Stata Fundamentals 为主线。CSDIY 提供了成熟的自学组织方式和计算工具基础，可以帮助本项目形成稳定的 Git/GitHub、命令行、编程环境与可复现工作流。

## 当前设计

- 在 `LEARNING_PLAN.md` 中登记 CSDIY，定位为跨学科辅助参考。
- 在 `SOURCES.md` 中记录官网、源仓库、访问版本、许可证和使用边界。
- 按需选读与当前任务直接相关的章节，不把完整计算机课程表并入当前 Stata 主线。
- 保持第三方内容在线只读；如果日后需要本地材料，再单独登记版本和许可证。

## Wiki 长期候选

项目未来可能演化为 Wiki 或知识站点。现阶段继续使用 Markdown 和 GitHub 作为唯一事实来源，不选择引擎，不生成配置，也不部署站点。

满足以下任一条件时重新评估：

1. 学习日志、练习与项目形成稳定的多层目录，README 导航开始难以维护。
2. 同一概念频繁出现在经济学、政治学、Stata 与计算方法等多条路线中，需要双向链接。
3. 已积累足够多的原创解释与可复现案例，可以面向他人组织知识入口。

届时再比较 GitHub Wiki、MkDocs、Docusaurus 等方案，并以迁移成本、中文搜索、公式与代码展示、Git 历史和部署维护为选择标准。

## 边界

- 当前不改变第一阶段课程和下一次学习起点。
- 当前不克隆 CSDIY，不复制其课程内容。
- 当前不创建 Wiki 分支、站点目录或自动部署流程。
