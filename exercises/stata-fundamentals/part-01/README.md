# Part 1 — Introduction

## 本部分目标

- 认识 Stata 界面、数据、变量和观测值。
- 使用 do-file、help 和 log 建立可重复的操作习惯。
- 加载、检查、筛选、汇总和交叉分析数据。
- 创建、重编码和标记变量。

## 课程入口

本地课程文件：

```text
upstream/Stata-Fundamentals/lessons/01_introduction.do
```

完成练习前不打开：

```text
upstream/Stata-Fundamentals/lessons/01_introduction_solutions.do
```

## 完成步骤

1. 确认 Stata 能正常启动并打开课程 do-file。
2. 逐段运行示例，给每段代码写一句自己的解释。
3. 遇到 challenge 时先在自己的 do-file 中作答。
4. 记录报错、尝试过程和最终输出。
5. 完成后对照 solution，解释差异。
6. 更新根目录 `PROGRESS.md` 和当日学习日志。

## 本部分验收

- 至少一个独立编写且可重新运行的 `.do` 文件。
- 至少两个不看 solution 完成的数据操作任务。
- 一份简短说明，能够解释使用的主要命令及其结果。
